Direction Comparison

1. Classic *arr

  • Maximum information density
  • Table-driven, scannable

  • Traditional sidebar nav
Best for: Power users who want all data visible

2. Modern Dashboard

  • Card-based, visual hierarchy
  • Health status prominent
  • Spacious, breathable
  • Grouped navigation
Best for: Balanced polish + function

3. Minimal Control

  • Ultra-clean, centered
  • Status is the hero
  • Activity feed focus
  • Top navigation
Best for: "Calm technology" philosophy

4. Hybrid Dense

  • Icon sidebar (compact)
  • Split view with context
  • Queue always visible
  • Balanced density
Best for: Monitoring + action in one view
